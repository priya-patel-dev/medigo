# Medigo

AI-powered prescription safety and healthcare decision support platform designed to reduce medication risks and improve patient outcomes.

## Overview
Medigo is a healthcare-focused application that helps clinicians and care teams review prescriptions more safely by combining digital workflows with AI-assisted insight. The platform is built to improve visibility, reduce risk, and support better decision-making in clinical environments.

## Features
- AI-assisted prescription review
- Medication safety checks and risk awareness
- Clinical workflow support for care teams
- User-friendly healthcare interface
- Structured decision support for safer review practices

## Tech Stack
- Frontend: React + TypeScript + Vite
- Styling: Tailwind CSS
- State management: React app logic / UI state
- Deployment: Vercel

## Run locally
```bash
npm install
npm run dev
```

## Project goal
To improve medication safety by making prescription review more transparent, reliable, and supportive for healthcare teams.
